# c028 花・壁紙の設定

既存プロジェクトのSQL Editorで **c028-appearance.sql のみ** を実行します。schema.sqlの再実行や既存テーブルの削除は不要です。未適用でも会話記録は従来どおり使えますが、花選択と写真壁紙はロックされます。

## 検証用の権限ON/OFF

1. Authentication → Usersで、HanaTalkにログインしているGoogleアカウントのユーザーUUIDを確認します。Supabase管理画面にログインする管理者アカウントとは別です。
2. SQL Editorで、次のUUIDをそのユーザーのものに置き換えて実行します。

```sql
insert into public.entitlements(user_id,premium)
values('ユーザーUUID'::uuid,true)
on conflict(user_id) do update set premium=excluded.premium;
```

OFFにする場合：

```sql
update public.entitlements set premium=false
where user_id='ユーザーUUID'::uuid;
```

3. HanaTalkで対象アカウントのクラウド同期を有効にし、「設定 → 花」を開き直します。表示中は約60秒ごとにも確認します。自分のアカウントも同じ制限を受けます。

`preserved_through` と `free_periods` は自動管理です。直接編集・行削除はしないでください。OFF時点の当月までは花を保持し、翌月以降は基本に戻します。再度ONにしても無料期間の過去月は基本のままです。

## セキュリティと制約

- entitlementsはRLS有効・本人のSELECTのみ。利用者にINSERT/UPDATE/DELETE権限はありません。
- 花の設定はsettingsの `flowerMonth:YYYY-MM` に保存します。DBトリガーがPremium・所有者・花ID・当月以降を検査するため、直接RESTや旧同期RPC経由でも制約は同じです。
- セット変更は1トランザクション。先月以前は変更不可。反映対象は選択した年の当月以降です。
- 新しい選択はオンライン必須。会話入力は従来どおりオフライン可。権限が確認できない場合は選択をロックし、確認済みの過去の花は維持します。
- 3色の無地壁紙は無料。写真壁紙は端末内のみで、JPEGに変換・縮小して保存します。認証情報・写真をクラウドの設定に含めません。
- 写真壁紙のローカル表示はクライアント側制御です。ブラウザ自体を改造した利用者による見た目の変更を防ぐDRMではありません。サブスク情報とクラウドの花設定変更はDBで保護します。
- 契約・決済・期限切れの自動処理は未実装。将来、決済Webhookなど信頼できるサーバーからentitlementsを更新します。秘密鍵はフロントに置きません。
- 「ロック解除」は準備中の案内です。購入や課金は発生しません。

## 公開前の実機確認

SQL適用後にA/BユーザーでON/OFF、本人以外の読書き拒否を確認してください。自動テストはPGlite上で実行しており、本番Supabaseへの適用・実アカウント検証を代替しません。

1. 無料で人物登録、花タブ閲覧、3色の壁紙変更ができる。
2. ONで花を変更し、確認のキャンセルでは変わらず、確定で月初まで変わる。
3. 過去月は変更不可。カレンダーと入力画面が同じ花になる。
4. OFFにして選択がロックされても、当月・過去の花が残る。
5. 別端末の同期後、同じ月の花になる。写真は元の端末だけに表示される。
6. Security AdvisorでRLS・関数・公開権限を確認する。

花の種類追加、追加セット、濃さスライダー、課金導線は今後の拡張です。
